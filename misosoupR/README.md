# misosoupeR 

This repository provides some tools to analyse results generated by `misosoup`.

### Main scripts

* `main_singleSol_private.R` This is the main script modified for private use. It takes one set of solutions and performs the "stat" and/or "aggr" analysis described below, and their respective plots. It can restrict the analysis to selected subsets of solutions.

* `main_multipleSols_private.R` This script  takes sets of solutions and compares all-against-all to identify those solutions at the intersection and those  present  in only one of the members of each pair. Each subset is printed in one file for each pairwise comparison. It  also extract some statistics of these comparisons, returning some box plots and a table with quantiles.

### Functions

**Data transformation**

* `load_solutions.R`: This function takes a character vector in which each entry is a path to a yaml file and it creates a single list with all solutions. The expected structure (and the one generated) is a list with the following  hierarchy `list[[medium]][[strain]][[solution]]`.
* `sol_to_exchange_network.R` This function takes a solution from a yaml file and extracts exchanged reactions for metabolites not present in the base medium. Therefore, it also requires a yaml file with the metabolites present in the medium. It returns a dataframe representing a directed network, in which negative (positive) values represent a metabolite consumed (excreted) by a species.

**Networks of a single set of aggregated solutions (_aggr_ analysis) **

* `aggregate_networks.R` This function aggregates solutions computing either the mean across a set of solutions or the proportion of observations happening across a set of solutions. An observation is here understood as the secretion or consumption of a metabolite by a given species across the set of solutions. Note that secretions and consumptions are considered different observations. Aggregation can occur for each specific combination of C source and species or it can additionally be aggregated either fixing a C source and aggregating all solutions for all species or the other way around, fixing a given species and aggregating C sources. It can also aggregate all C sources and species into a single solution (the default). The function also accepts a vector of species or C sources indicating subsets of interest.
   * `rename_net`: An auxiliary function that renames metabolites depending on whether they are excreted (out) or consumed (in).
   * `net_aggr_to_out.R`: This function works on the data frames containing all solutions to provide a single aggregated output for each of them (i.e. means of the fluxes and the proportion of solutions in which each metabolite was observed).
   * `output_networks.R` Funciona para graphs e imprimir los networks, terminar para heatmaps y convertir en función. No funciona aún como función, verificar que el paso de argumentos a las funciones funciona.
       * `functionArgsList.R` Auxiliary function combining user-provided and default arguments.
       * `heatmap.2.mod.R` A  minor modified version of `heatmap.2` allowing you more control of x and y axis labels.

**Comparison of one or more sets of solutions**

* `stat_comparison_sets_solutions.R` This function considers a list containing at least two data frames,  each of them obtained with the function "summary_stats_solutions", and it creates a box plot for each of the variables contained in these dataframes to compare their distribution. It also creates a table with the quantiles of each variable and dataset.

**Match two or more sets of solutions**

* `match_sets_pairwise.R` This function takes two sets of solutions following the same structure, i.e. a list with keys sols[[medium]][[strain]][[solution]] and it looks for those solutions in common, meaning that they have the same medium, strain and suppliers, but possibly not the same reactions. 

* `match_sets_multiple.R` This function takes two sets of solutions following the same structure, i.e. a list with keys sols[[medium]][[strain]][[solution]] and it looks for those solutions in common, meaning that they have the same medium, strain and suppliers, but possibly not the same reactions.
